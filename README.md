# Hi, I'm John

I build AI-powered tools to help PMs move faster on their day-to-day work.

**Current projects:**
- [prd-generator](https://github.com/j4wang/prd-generator) - Template-based tool that generates a first-draft PRD from 
your inputs, so you can spend time refining rather than starting from scratch.
- [pm-research-tool](https://github.com/j4wang/pm-research-tool) - Researches companies and industries using customizable 
question templates, built for quick pre-meeting or market research.
- [olist-retention-analysis](https://github.com/j4wang/olist-retention-analysis) - Cohort retention and Day-N repurchase analysis on the Olist Brazilian e-commerce dataset, examining what separates the ~3% of customers who return from those who don't.
- [olist-churn-prediction](https://github.com/j4wang/olist-churn-prediction) - Binary churn classifier built on the same dataset. The model performs poorly (ROC-AUC ~0.57), which is itself the finding. The first-order data doesn't predict return behavior.
- [udacity-ab-test-analysis](https://github.com/j4wang/udacity-ab-test-analysis) - End-to-end A/B test analysis of Udacity's free trial screener. The experiment is underpowered and returns a split result. Since gross conversion drops significantly, net conversion is inconclusive with downside risk. Recommendation: do not ship.
